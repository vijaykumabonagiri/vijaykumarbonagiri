# E-Commerce Mobile App UX Case Study

## Project Overview
Designed a mobile shopping experience to improve product discovery and checkout conversion.

## Problem
Users abandoned carts due to a complicated checkout process.

## My Role
UI/UX Designer

## Process
- User Research
- Competitive Analysis
- Personas
- User Flows
- Wireframing
- UI Design
- Usability Testing

## Tools
- Figma
- FigJam
- Miro

## Key Outcomes
- Reduced checkout steps from 6 to 3
- Improved usability and navigation
